A program that writes one one-line joke about working beside AI coding agents, for make.fun's "The joke about the demo" bounty. The joke: a coding agent rewrites the whole demo five minutes before showtime — and leaves the bug untouched.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (UTF-8, one line, no network, deterministic — every run writes the same bytes).
